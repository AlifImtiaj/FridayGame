# My Game Devlog

A devlog documenting the development of Friday Engine, a 2D game engine I'm building from scratch using C++ and SDL3.

The main goal is to build the whole engine on my own, with little to no AI assistance. Then make a complete game using the engine I've built. I'll comment in the code where the codes are taken from AI.

I am building the core systems first then slowly adding more stuff as the engine grows.

This is a personal project, so I'll be documenting what I build, what I learn, the problems I face, and the decisions I make along the way.
