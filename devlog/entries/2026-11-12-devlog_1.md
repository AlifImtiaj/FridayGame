# Devlog #01 — Engine Initialization & Image Rendering

## What I worked on

For the first devlog, I worked on the engine initialization and the Image class.

Since I had worked with SFML before, a lot of the initialization part in `Engine.cpp` felt fairly similar to SFML. I was already familiar with the general idea of creating a window, setting up a renderer and getting things ready for the main loop.

SFML already had a direct way to handle deltatime, so I never really had to think much about how to do it myself. With SDL3, I had to figure that part out on my own.

## What I implemented

**Engine Initialization & Delta Time**

I started by setting up the basic engine initialization in `Engine.cpp`. Since I already had some experience with SFML, getting the basic setup running wasn't particularly difficult.

The interesting part was handling delta time. In SFML, there are convenient ways to measure elapsed time, but I couldn't find a direct equivalent to what I was used to in SDL3. So, I had to come up with my own approach.

At first, I thought about using a simple delay, but I wanted something better than that. I wanted proper frame timing, where the engine could calculate how much time each frame took and delay the next frame when necessary to maintain the target FPS.

**Image Class & Rendering**

After getting the basic engine setup working, I moved on to the `Image` class.

I made it so an image can be created with a file path, with optional position, scale, and rotation. The class loads the image using SDL_image, converts it into a texture, and stores its original dimensions so it can calculate the destination rectangle for rendering.

I also added setters and getters for position, scale, rotation, and image size, along with horizontal and vertical flipping.

One thing I made sure to do was destroy the temporary surface after creating the texture. The texture is what gets used for rendering, so there's no need to keep the surface around afterward.

I also came across `SDL_SetRenderLogicalPresentation()`, which looks like it will come in very handy for handling different window sizes and keeping the game's rendering consistent across resolutions.

## Problems I ran into

**Getting Delta Time and FPS Control Right**

The biggest challenge was figuring out how to handle delta time and frame timing properly.

The problem was that I couldn't just use the same approach I was used to with SFML, so I had to figure out a different way.

At first, I thought about using `SDL_Delay(16)`, since that's roughly how long a frame should take at 60 FPS. But that doesn't account for the time already spent processing and rendering the frame. Depending on how quickly each frame rendered, the FPS could fluctuate around 57-62.

I wanted something more precise than simply adding a fixed delay to every frame.

## How I solved them

**Implementing My Own Frame Timing**

I went searching through Google and YouTube to understand how other developers handled frame timing. After learning a bit more and tweaking the approach myself, I came up with a solution using `std::chrono::steady_clock` and `SDL_DelayPrecise()`.

The engine measures the time between frames to calculate delta time. For FPS control, it tracks the next expected frame time and delays only for the remaining time when a frame finishes early. I also added a small delta time cap to prevent unusually large values from being passed into the update loop.

I added some basic keyboard controls too: 0 for uncapped FPS, 1 for a 60 FPS target, and 3 to toggle VSync.

It's not some revolutionary system, but it does what I wanted, and I'm happy with how the initial implementation turned out.

```cpp
using clock = std::chrono::steady_clock;

    auto previousStart = clock::now();
    auto nextFrame = previousStart;

    while (m_isGameRunning) {
        const auto frameStart = clock::now();

        m_deltaTime = std::min(
            std::chrono::duration<float>(frameStart - previousStart).count(),
            0.1f);
        previousStart = frameStart;

        Tick();

        if (m_isVsyncOn)
            continue;

        if (m_targetFPS > 0) {
            nextFrame += std::chrono::duration_cast<clock::duration>(
                std::chrono::duration<double>(1.0 / m_targetFPS)
            );

            const auto now = clock::now();
            if (nextFrame > now) {
                SDL_DelayPrecise(static_cast<Uint64>(
                    std::chrono::duration_cast<std::chrono::nanoseconds>(
                        nextFrame - now).count()));
            }
            else {
                nextFrame = now; 
            }
        }
        else {
            nextFrame = clock::now(); // this is for uncapped fps
        }
    }
```
